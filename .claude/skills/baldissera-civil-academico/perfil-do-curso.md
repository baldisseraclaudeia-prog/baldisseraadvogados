# Perfil do curso — preencher uma vez, reaproveitar em toda peça

Preencha o que souber e deixe o resto em branco: o agente presume o que faltar
e declara a presunção. Nada aqui é obrigatório — mas cada campo preenchido é
uma correção que o aluno não precisa fazer depois.

Para usar: mande este arquivo preenchido junto com o primeiro enunciado, ou
diga "usa meu perfil do curso".
